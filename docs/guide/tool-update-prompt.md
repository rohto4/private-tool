# ツール情報更新プロンプト

## 概要

このプロンプトは、コーディングLLMツールの比較データを更新するためのものです。
AIに投げることで、最新情報に基づいてツールデータを更新します。

## プロンプト

```
以下のコーディングLLMツールの情報を最新の情報に更新してください。

## 更新対象ファイル
- `src/data/tools.ts` - ツール情報
- `src/data/comparison.ts` - 比較項目（必要に応じて）

## 更新項目

### 基本情報
- 公式サイトURL
- 概要説明
- 主な特徴
- 価格モデル（無料/有料/両方）
- 料金詳細
- 対応LLMモデル
- オープンソース有無
- 対応IDE
- リリース年
- 開発元
- 主な利用シーン

### 評価（5段階）
各ツールの評価を見直してください。評価は以下の基準で行ってください：
- 5: 非常に優れている（業界トップ）
- 4: 優れている
- 3: 平均的
- 2: やや劣る
- 1: 大幅に劣る

## 更新手順

1. 各ツールの公式サイト、ドキュメント、GitHubを確認
2. 最新の料金プラン、機能、対応モデルを調査
3. 新しいツールが市場に出ている場合は追加を検討
4. 既存ツールの評価を見直し
5. `src/data/tools.ts` を更新
6. 必要に応じて `src/data/comparison.ts` を更新
7. `npm run build` でビルド確認
8. 日付を更新（ファイル冒頭のコメント）

## 注意事項

- 評価は客観的な情報に基づいて行ってください
- 価格情報は変動が激しいため、確認日を記録してください
- 新しいツールを追加する場合は、既存のデータ構造に従ってください
- ビルドが通ることを確認してからコミットしてください
```

## 使用方法

1. 上記のプロンプトをAIに投げる
2. AIが最新情報を調査してデータを更新
3. ビルド確認後にコミット・プッシュ
